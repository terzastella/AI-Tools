# git — `git` v1.1 (foto prima/dopo, solo leggere)

- `branch`: branch corrente, `staged`: cosa sta in staged, `blame`: chi ha toccato una riga (`path` + `line`).
- Non committa, non pusha. Se non sei in repo git dice `NOT_GIT` chiaro.
