# Security Policy

## Reportare una vulnerabilità

**Non aprire issue pubbliche.** Scrivi a `terzastella` via messaggio privato su
GitHub con: descrizione, passi per riprodurre, impatto stimato. Risposta attesa
entro qualche giorno; fix e credito nel CHANGELOG.

## Cosa ci aspettiamo tu NON faccia

Test solo su tue copie locali. Niente scanning o exploit contro
infrastrutture altrui.

## Scope

`packages/agent-tools/src/` (policy, guard, tool che eseguono codice/rete),
`servers/ai-tools-mcp/server.mjs`. Fuori scope: singoli script in `packages/py-ref/`.
